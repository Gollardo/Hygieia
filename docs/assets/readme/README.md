Replace a screenshot only after a material UI or behavior change. Before
committing a replacement:

1. use synthetic or explicitly public data only;
2. inspect the full image at original resolution for paths and personal names;
3. retain dark-first hierarchy, accessibility redundancy, and Reduce Motion
   behavior;
4. record the captured product state and exact dimensions here;
5. compare the result with the accepted Lustral Field reference or previous
   accepted state.
