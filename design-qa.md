# Lustral Field Design QA — public record

## Scope

The accepted direction is **Lustral Field**: a dark native macOS hierarchy with
a restrained constellation atmosphere, exact data geometry, and coral reserved
for the active territory or destructive emphasis.

This public record includes only captures that contain no local filesystem
names, paths, or personal data. Earlier explorer comparison images intentionally
remain outside the public history. No public explorer screenshot is currently
claimed as pixel evidence.

## Empty state

The scene uses one native window title plus a quiet emblem, a full-bleed Lustral
constellation field, and a lower-left editorial composition. The primary action
and read-only safety promise remain visible without turning the state into a
modal dialog.

The current app extends this composition with local-volume entry while keeping
the system folder picker as the precise secondary scope.

## Loading state contract

Loading remains in the same spatial world as the explorer. A bounded sweep
crosses the generated field while a compact glass panel reports the selected
root, item and folder counts, reported bytes, elapsed time, and Cancel action.
The UI does not present an invented exact percentage when the scanner cannot
support one. A live loading capture is not included because scan counts and
reported sizes are filesystem telemetry unless the entire runtime fixture is
synthetic.

## Explorer contract

The implemented explorer uses three information regions: bounded Largest Items,
the dominant perspective field, and an evidence/review band. The raster nebula,
deterministic particles, and sparse connections remain decorative and
subordinate to `FileTree`-derived sectors, labels, hit targets, and actions.

The public repository intentionally does not include a live explorer capture
until one can be produced from synthetic data through the same native runtime
without exposing local filesystem evidence.

## Fidelity and accessibility surfaces

- typography uses native San Francisco with monospaced digits for changing
  measurements;
- charcoal, glacier, aqua, coral, amber, and destructive red retain semantic
  roles;
- atmospheric images and particles are hidden from accessibility;
- Reduce Motion disables atmosphere pulse and scan sweep;
- long filenames truncate without changing the layout grid;
- visualization geometry and hit testing remain deterministic and do not add
  filesystem work or per-node animation.

## Residual gates

- light appearance and text-scaling extremes;
- VoiceOver traversal and keyboard-only usability on a signed app;
- measured Apple Silicon rendering performance;
- a synthetic-data public explorer capture compared with the accepted state;
- signed sandbox Finder/Trash interaction and read-only-volume behavior.

The visual direction is accepted. The residual items above remain verification
gates and are not implied by the checked-in empty-state capture.
